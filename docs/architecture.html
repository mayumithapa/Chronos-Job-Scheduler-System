Chronos

High-Level Design

1 · Two processes

API only schedules. Worker only executes. A slow job can never block the API; a worker crash never kills HTTP.

2 · Two stores

Postgres = durability (every job and every run). Redis = speed (queue + delayed delivery). If Redis is wiped, jobs are recoverable from Postgres.

3 · Horizontal scale

Run 1 API and N workers on the same queue — BullMQ load-balances jobs automatically. docker compose up --scale worker=5.
